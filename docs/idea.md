# Idea: Perimeter

## Problem
VCs learn late when something changes around their bets: a rival raises, a shared investor backs a competitor, a board member sits on both sides, a regulator acts.

## Target user
Partners and platform teams at early-stage VC funds.

## Solution
Paste a portfolio. Perimeter maps everything around each company from Cala's knowledge graph (rivals, investors, people, corporate events), flags overlaps only a graph can see, and keeps a quiet, sourced feed. One-off company checks in under a minute. Every fact links to its Cala source.

## Demo script
1. Start: load demo portfolio (real companies).
2. Feed: overlaps and rival moves, open a source chip, draft a note to a founder.
3. Map: graph view, shared investors light up.
4. Check: live check of a rival, report with sourced findings.
5. Ask (Ctrl+K): a free question answered by Cala with citations.

## Judging criteria
- Real Cala data, sourced; speed; polish.
